# V2-015：单场简历面试支持 10 题

## Outcome

用户选择一份简历后，可在练习配置中选择 1～10 道题；请求 10 题时，系统返回 10 道不同且绑定简历证据的问题。

## Relevant context

- 前端和 API 当前将 `questionCount` 限制为 1～4，默认 3。
- 简历检索每个能力只产生一个候选；目标岗位通常只有 4 个能力候选，单纯放宽上限会创建失败。
- 到期复测题仍可占用一个题目位置，总题数不超过用户选择值。

## Constraints

- 默认题数保持 3，不强制所有用户完成 80～100 分钟面试。
- 不降低证据要求，不用无关题填充数量。
- 不改变两轮追问、评分、Attempt、Weakness 或复测状态机。

## Acceptance

1. UI 与 API 接受 1～10，拒绝 0 和 11。
2. 稀疏简历仍能围绕证据核验、方案取舍、结果验证三个角度生成 10 道唯一问题。
3. 每道题保留至少一个简历证据引用，且首轮优先覆盖不同能力。
4. 单元/数据库测试、TypeScript、ESLint 和 production build 通过。

## Risks

- 10 道基础题加动态追问可能显著延长面试时长；UI 必须继续显示预计时长。
- 同一能力可能出现多道题，必须通过不同角度和不同证据锚点控制重复度。

## Return contract

- 列出前端、API、检索与测试变更。
- 报告 10 题唯一性和证据覆盖测试。
- 不推送、不部署，除非用户另行授权。
