# AI Mock V2.0.0

AI Mock V2 把“一次性面试打分”升级为可重答、可追溯、可复测的训练闭环，并提供无需开发环境的 Windows x64 便携版。

## 本版交付

- PDF / DOC / DOCX 简历解析，基于简历证据生成最多 10 道唯一问题；
- 首答 → 受控追问 → 重答 → 弱点 → 等价题复测的训练闭环；
- 受限状态机 Agent，只读 Tool 白名单、两轮追问上限、低置信度与超时降级；
- 双域 Hybrid RAG、结构化 Memory、可回放 Trace 与 Bad Case 关联；
- 318 条版本化冻结评测样本、14 条 Hybrid RAG Gold Query 和 Promptfoo CI 回归；
- Windows x64 便携 ZIP，自带 Node.js、PostgreSQL、演示数据库和一键启停脚本。

## Windows 便携版

1. 下载 `AI-Mock-Portable-Windows-x64-v2.0.0.zip`并解压。
2. 双击 `START_AI_MOCK.cmd`。
3. 打开 `http://127.0.0.1:3000`，使用包内 `README.txt` 的演示账号。
4. 测试后双击 `STOP_AI_MOCK.cmd`再移动或删除文件夹。
