### V2.1 — 动态追问（Follow-up Agent）

PRD 第五章 5.1 定义了三种追问决策：

| 决策 | 触发条件 | 系统动作 |
|------|---------|---------|
| 深挖追问 | 回答出现数字/决策/结果，但未说明行动或依据 | 追问"具体做了什么/如何证明结果" |
| 澄清追问 | 回答含糊、答非所问、缺少必要背景 | 要求补充背景或重新聚焦 |
| 收束评分 | 回答完整或达到追问上限 | 停止追问，进入评分 |

**实现要点：**
- [x] Follow-up Agent prompt 设计（判断深挖/澄清/收束）
- [x] 追问轮次上限：2 轮（PRD 5.3 明确规定）
- [x] 追问 UI：紧接原题插入追问，用户继续作答
- [x] 追问答案与主答案关联存储（`followUpRound`）
- [x] 追问质量评测：分类评测集门禁已启用
- [x] Badcase 防护：重复、跑题、过度追问

**当前基础：**
- 简历模式已有简化追问（`shouldFollowUp` + `createResumeFollowUp`）
- `Answer` 表有 `followUpRound` 字段
- `MockSession` 表有 `followUpRound` 字段
- 需要泛化为通用追问引擎（不限于简历模式）
